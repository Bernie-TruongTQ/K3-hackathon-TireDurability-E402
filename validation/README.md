# Validation CP5

Mỗi phiên khoảng 10 phút:

1. Giao task thật: “Hãy dùng công cụ để hiểu phần hình/bảng/công thức này”.
2. Im lặng quan sát; không hướng dẫn.
3. Hỏi:
   - Điều gì khó hiểu hoặc khó chịu nhất?
   - Kết quả này bạn có tin không, vì sao?
   - Bạn có dùng thật không, vì sao/chưa?
4. Ghi quote nguyên văn vào `feedback-log.csv`.

Danh sách tester, task và cách chia phiên: `cp5-test-plan.md`.
Mỗi phiên dùng một bản sao của `cp5-observer-form.md`.
File có thể gửi trực tiếp cho tester: `cp5-tester-instructions.md`.
Bộ câu hỏi chia riêng cho 5 tester: `cp5-scripted-question-sets.md`.

Điều kiện hoàn thành:

- [x] ≥5 feedback từ ≥5 người ngoài nhóm.
- [x] Có ≥2 willing users đã khai từ CP1.
- [x] Có tên/vai, quan sát và quote nguyên văn.
- [x] Ít nhất một thay đổi được ghi vào `spec.md` §9, hoặc giữ nguyên có lý do.

Tổng hợp: `cp5-results-summary.md`.

Provenance: dữ liệu do tester báo cáo và được đại diện nhóm xác nhận ngày
2026-07-30. Nhóm giữ nguyên cả phản hồi tích cực và case fail.
